Historique

    Réglages

    Clé API Venice

    Stockée dans le trousseau du système (Keychain, Credential Manager, Secret Service), jamais en clair sur le disque. Obtenir une clé

    Modèle et génération

    « Automatique » suit le modèle recommandé par Venice, qui évolue avec le catalogue.

    Instructions système

    Enregistrez plusieurs jeux d'instructions (rôle, ton, format…) et choisissez-les pour chaque conversation dans le menu en haut de la fenêtre. Celui marqué « par défaut » s'applique aux nouvelles conversations.

    Modèles de messages

    Textes réutilisables : tapez / dans la zone de saisie, puis le début du nom, et validez par Entrée.

    Confidentialité

    Les modèles « anonymisés » (◐) sont fournis par des tiers (OpenAI, Anthropic, Google, xAI…) : Venice leur transmet vos requêtes sans votre identité, mais ces fournisseurs peuvent les conserver selon leurs propres règles.

    Interface
    Chiffrement des données

    XChaCha20-Poly1305, clé de 256 bits gardée dans le trousseau du système. Sans cette clé (réinstallation, nouvel ordinateur, trousseau réinitialisé), les données chiffrées sont illisibles : conservez la clé de récupération dans votre gestionnaire de mots de passe (KeePassXC, Bitwarden…).

    Mises à jour

    Seule requête : api.github.com/repos/r0mish/Venice-Desktop/releases/latest, sans identifiant.

    Avancé

    Compatible avec un serveur auto-hébergé exposant l'API OpenAI (vLLM, Ollama, llama.cpp…), par ex. http://localhost:11434/v1. HTTP autorisé seulement sur localhost. Images, voix et recherche intégrée nécessitent l'API Venice.

    Données locales :

    Recherche web

    Avec Brave, Google ou SearXNG, le modèle formule lui-même ses requêtes (outil web_search) et peut en lancer plusieurs. SearXNG : activez le format JSON (search.formats: [html, json] dans settings.yml). Les pages lues par fetch_url sont téléchargées depuis votre machine ; les adresses du réseau local sont bloquées.

    Génération d'images

    Bouton « Image » de la zone de saisie (onglet Chat). Les images sont stockées dans la conversation, sur cet appareil (chiffrées si le chiffrement est actif).

    Vidéo et musique

    Boutons « Vidéo » et « Musique » de la zone de saisie. Le prix estimé s'affiche avant la génération ; le résultat est supprimé des serveurs de Venice dès qu'il est récupéré, puis stocké sur cet appareil (chiffré si le chiffrement est actif).

    Dictée vocale

    Le son est capté en mémoire uniquement (jamais écrit sur le disque) puis envoyé pour transcription à l'API Venice, ou à votre serveur compatible /v1/audio/transcriptions (Speaches/faster-whisper, whisper.cpp, vLLM…). La clé Venice n'est jamais transmise à un serveur personnalisé.

    Lecture à voix haute

    Clonage : un échantillon de 10 à 30 s d'une voix claire, avec l'accord de la personne. L'échantillon est envoyé à Venice et à son fournisseur (Resemble AI).

    Bouton haut-parleur sous chaque réponse. Les voix dépendent du modèle. L'audio est lu en mémoire, jamais enregistré.

    Documents PDF

    Le texte des PDF est extrait localement, rien n'est envoyé pour la conversion. Pour un PDF scanné (sans texte), passez-le d'abord dans un OCR local comme ocrmypdf, ou joignez des captures à un modèle « vision ».

    Serveurs MCP

    Même format que Claude Desktop. Serveurs locaux (command) ou distants (url + headers). Protocole MCP 2026-07-28, avec repli automatique pour les serveurs plus anciens.

    Outils toujours autorisés
    Agent de code

    L'agent ne peut lire et écrire que dans le dossier de projet choisi. Les commandes s'exécutent avec vos droits : en mode « Tout demander » ou « Modifs auto », chacune doit être approuvée ; en mode Autonome, aucune. Le mode se change à tout moment pour la session en cours (menu en haut).

    Dossiers de projet autorisés
    Consommation

    Tokens exacts renvoyés par l'API ; coûts estimés d'après les tarifs publiés dans la liste des modèles de Venice (ou vos tarifs personnalisés). Votre relevé fait foi : venice.ai.

    Solde du compte

    Le solde est vérifié au plus toutes les 10 minutes après vos échanges ; le budget compare les coûts estimés du mois en cours (alerte à 80 % et 100 %).

    Tarifs personnalisés ($ par million de tokens, facultatif)

    Utile pour un serveur auto-hébergé ou pour corriger un tarif. Une ligne par préfixe de modèle : préfixe = entrée / sortie. Le préfixe le plus long l'emporte.
    Serveurs SSH

    Nouveau serveur

    Utilise le client OpenSSH du système : vos alias, ProxyJump et clés de ~/.ssh/config s'appliquent. Par mot de passe, les codes 2FA sont demandés à la connexion, puis la connexion est réutilisée 10 min (sauf sous Windows, où chaque commande s'authentifie).

    Connexion SSH

    Mot de passe refusé, réessayez.

    Nouveau projet

    Dossier de travail (agent de code)
    Aucun : chaque session de code choisit son dossier
    Fichiers de référence

    Texte, Markdown, code, CSV ou PDF. Leur contenu accompagne chaque message envoyé dans le projet : préférez des documents ciblés. Stockés uniquement sur cet appareil.
